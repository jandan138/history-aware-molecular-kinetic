# ADR 0011 — E4 is causal steering, not breadth collection

**Status:** accepted.

## Context

E3 established the first exact Hero: a one-degree physical edit to one selected
collision creates a visibly different future, and conservative causal branching
reuses independent history while matching a complete resimulation.

That result leaves one important authoring question unanswered. In E3, the paper
hands the creator collision #2. A creator normally starts from the opposite end:
they know which future feature they want to change, but not which earlier event is
the useful cause.

The previous generic E4 outline mixed native acceleration, edit-family breadth,
geometry changes, density cases, and an interaction prototype. Those are useful
future investments, but they do not form one next paper act.

## Decision

E4 is a single causal-steering Hero:

> **Select a future feature, find a past collision, and direct an exact new future.**

The registered `Erase One Stroke` session keeps the E1/E3 exact-reverse world. The
creator selects the recovered `E`'s upper horizontal stroke. The system traces that
terminal particle set backward through the unedited collision DAG, ranks the first
16 collisions by target-descendant coverage and purity, and exposes a four-angle
exact local-preview palette for the three highest-ranked collisions. It saves one
chosen branch and only then runs one complete resimulation as the final reference.

The E1 `N=128` realization has no foreground particles inside the middle stroke's
interior. The target is therefore the nonempty upper stroke, fixed before any E4
branch outcome is inspected. This preserves the intended “change one future
feature” interaction rather than creating an empty visual target.

## Consequences

- E4's new contribution is **outcome-to-cause navigation**, not a new perturbation
  operator. It keeps E3's conservative pair-relative-velocity rotation.
- The small branch palette is a creator operation, not a parameter sweep or an
  evidence matrix. Candidate ranking uses baseline ancestry only.
- The interaction artifact is a self-contained local browser view of exact cached
  previews. The renderer never changes the physics.
- One saved branch receives the full local-versus-global correctness check. Every
  preview uses the same exact local causal scheduler, but does not launch a global
  oracle.
- Existing Python reference previews are already short enough for this bounded
  Hero. Native execution is a contingency only if the registered interaction
  latency gate fails; it is not an E4 headline.
- Geometry edits, multiple edit families, density/seed grids, `N=512`, GPU work,
  and a user study remain out of E4 scope.

## Story consequence

The active route becomes:

```text
E1: a frame is not a future
E2: a slider is not a history
E3: one past collision is editable
E4: a desired future can locate its editable cause
```

E4 may claim **causal steering** only for its registered Hero. If the exact
interaction works but the selected feature cannot be changed more than collateral
foreground, the language narrows to **causal exploration**. No extra defensive
experiments are added to rescue that distinction.
