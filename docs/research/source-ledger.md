# Source Ledger

The machine-readable source of truth is the repository file
`references/sources.yaml`.

It records:

- hard-sphere kinetic-limit papers and their exact claim boundaries;
- backward-cluster and correlation-error context;
- velocity-inversion/Loschmidt prior art;
- reversible elastic-collision algorithms;
- generic discrete-event rollback/Time-Warp prior art;
- EDMD/DSMC/Enskog and adaptive-solver references;
- graphics kinetic and visual-system references;
- official venue-scope documents for the current SIG/VIS planning cycle;
- exact upstream repository revisions and licenses;
- project role and process-isolated integration method;
- claims supported and claims explicitly not supported.

## Active claim-boundary use

The source ledger prevents the project from claiming:

- first velocity-reversed hard-sphere echo;
- first reversible elastic-collision simulation;
- first event-log rollback system;
- first EDMD–DSMC hybrid;
- implementation of the Deng–Hani–Ma cutting proof;
- theorem guarantees for causal branching or correlation surgery.

## Reproducibility rule

External revisions are updated intentionally through an ADR and adapter
revalidation. “Latest main” is never a reproducible oracle. Venue pages are recorded
as scope references and must be rechecked for the actual submission year.
