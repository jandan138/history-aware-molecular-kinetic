# Figures

Store figure recipes and compact derived data, not hand-edited final evidence.
Each primary figure must name all run IDs and renderer/config hashes.

## Active main figure

`MOLECULAR-TIME-MACHINE-E3-v0` generates
`figure-one-collision-two-worlds.svg/.pdf` from the same result object and renderer
as the neutral video. The six panels are: selected collision, addressable timeline,
one-degree edit, original terminal world, edited terminal world, and runtime causal
set. The frozen hashes and claim boundary are in the
[E3 result](../../docs/benchmarks/molecular-time-machine-e3-result.md).

## Active E4 interaction figure

`MOLECULAR-TIME-MACHINE-E4-v0` is frozen to generate
`figure-causal-steering.svg/.pdf`, a neutral `Erase One Stroke` video, and a
self-contained browser artifact. Its panels carry the full E4 story: select a
future feature, rank its past collision causes, choose a small physical edit, and
save one branch verified against full resimulation. The recipe is in the
[E4 preregistration](../../docs/benchmarks/molecular-time-machine-e4-preregistration.md).
