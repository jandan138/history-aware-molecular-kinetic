# b5_graphics_evidence

Shared-renderer visual evidence and hero scenes.

Candidate cases:

- `B5-ZOOM-MIX-v0.yml` — conversion, temporal continuity, camera/physics decoupling;
- `B5-CORRELATION-LABYRINTH-v0.yml` — matched-state history evidence;
- `B5-EXPANSION-VACUUM-v0.yml` — dynamic LOD visual flagship and Pareto evidence.

B5 consumes frozen B2–B4 artifacts. It must not introduce new simulation physics.
Render configurations live under `configs/render/` and outputs must include a
versioned render manifest.
